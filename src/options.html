Backref

Replace bug-tracker IDs in code comments, PR/issue descriptions and comments, and commit messages with clickable links.

Link rules

Each rule has a regular expression and a link template. Use {id} in the template to insert the matched text. The whole match becomes the link text — capture groups are ignored. To avoid partial matches inside identifiers, use word boundaries (\b) in your regex. The Active on field scopes a rule to specific hosts; leave it empty to apply on every configured host. Hosts referenced here are added to the Hosts section automatically on Save.

    Hosts

    Hostnames (or hostname/path) where the extension is allowed to run. Adding a host triggers a Chrome permission prompt — you must accept it for the extension to activate on that host. Examples: github.com, github.com/myorg. github.com works out of the box, and any host you reference under a rule's Active on is added here on Save.
